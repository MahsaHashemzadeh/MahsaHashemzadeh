# 🚀 Featured Projects

### 🎥 [Egocentric Video Understanding — MLDL Project](https://github.com/Group69-MLDL/MLDLProject)

Research-oriented work on **query-based segment retrieval and answer generation in egocentric videos**, including temporal localization with VSLNet, architectural variants, and video question answering with modern vision-language models.

**Focus:** Computer Vision · Video-Language Understanding · Temporal Localization · Multimodal AI

---

### 📝 [GLIMPSE — Multi-Document Summarization](https://github.com/Asterisks-NLP/GLIMPSE-ASTERISKS)

A research project for generating informative summaries from multiple peer reviews using a **Rational Speech Act (RSA)** framework, balancing informativeness and distinctiveness.

**Focus:** NLP · Text Summarization · Transformers · RSA · Research

---

### 🤖 [RAG PDF Chatbot](https://github.com/MahsaHashemzadeh/RAG-PDF-Chatbot)

A Retrieval-Augmented Generation pipeline for question answering over PDF documents, combining document preprocessing, semantic embeddings, vector retrieval, and local language-model generation.

**Technologies:** Python · LangChain · Sentence Transformers · ChromaDB · Transformers · Qwen

---

### 🛒 [EZShop — Full-Stack Retail Management System](https://github.com/MahsaHashemzadeh/EZshop-Software-System)

A full-stack software engineering project implementing a retail management system with product catalog management, inventory tracking, sales registration, persistent storage, REST APIs, and automated testing.

**Technologies:** Python · FastAPI · SQLAlchemy · Pytest · REST API · MVC-inspired Architecture

---

### 🧬 [Euclid Optimizer — Genetic Algorithm](https://github.com/MahsaHashemzadeh/EuclidOptimizer)

A Python implementation of a **Genetic Algorithm** for three-dimensional vector optimization using binary encoding, roulette-wheel selection, crossover, mutation, and evolutionary optimization.

**Focus:** Evolutionary Algorithms · Genetic Algorithms · Optimization · Soft Computing
